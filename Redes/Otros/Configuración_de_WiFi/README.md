# Configurar WiFi en Cisco Packet Tracer

Se configurar un router inalámbrico (cambiando su SSID a `packet` y protegiéndolo con clave WPA2) y a adaptar una laptop con un módulo Wi-Fi para conectarla a la red y administrar el router remotamente desde su navegador web.

# Glosario

SSID: **El nombre público de tu red Wi-Fi**.

- **WPA2:** La contraseña que protege el Wi-Fi.
    
- **GUI:** Panel de administración
