
# 🌐 Conexión de Routers

Proyecto realizado en **Cisco Packet Tracer** para practicar la conexión y configuración de diferentes dispositivos de red.

## 🎯 Objetivo

El objetivo del proyecto es configurar una red compuesta por diferentes routers, switches y dispositivos finales, permitiendo la comunicación entre distintas redes y practicando conceptos de **VLAN, direccionamiento IP, enrutamiento y acceso remoto mediante SSH**.

## 🖧 Componentes

El proyecto cuenta con:

- Routers Cisco.
- Switches Cisco.
- Computadores.
- Laptop utilizada para la conexión SSH.
- Servidor DNS.
- VLAN 10.
- VLAN 20.

## 🔧 Configuraciones realizadas

### 🔀 Conexión entre routers

Se conectaron varios routers para permitir la comunicación entre diferentes redes.

### 🏷️ VLAN

Se configuraron VLAN para separar dispositivos dentro de la red:

- VLAN 10.
- VLAN 20.

Esto permite segmentar los dispositivos y separar lógicamente el tráfico de la red.

### 🌐 Direccionamiento IP

Se configuraron direcciones IP en los dispositivos de red para permitir la comunicación entre las diferentes redes.

### 🔐 SSH

Se configuró el acceso remoto mediante **SSH (Secure Shell)**, permitiendo administrar un dispositivo de red de forma remota desde el PC destinado para SSH.

### 🌍 DNS

Se incorporó un servidor DNS para practicar la resolución de nombres dentro de la red.

## 🧪 Pruebas

El funcionamiento de la red puede comprobarse mediante:

- `ping` → comprobar conectividad entre dispositivos.
- `show ip interface brief` → revisar las interfaces y sus direcciones IP.
- `show running-config` → revisar la configuración de los dispositivos.
- `ssh` → comprobar el acceso remoto al dispositivo configurado.

## 🛠️ Herramienta utilizada

- **Cisco Packet Tracer**

## 📚 Propósito del proyecto

Este proyecto forma parte de mi **portafolio de aprendizaje en Ingeniería Informática** y busca demostrar la aplicación práctica de conocimientos de **redes, configuración de dispositivos, segmentación mediante VLAN, conectividad y administración remota mediante SSH**.
