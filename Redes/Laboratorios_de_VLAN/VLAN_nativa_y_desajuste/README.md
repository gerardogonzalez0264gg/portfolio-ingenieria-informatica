# Configurar la VLAN nativa y solucionar la discrepancia de VLAN nativa en Packet Tracer.

Identificar y corregir un error de desajuste de VLAN nativa (_mismatch_) entre switches. Se soluciona ingresando a la consola y configurando el mismo ID de VLAN en ambos extremos.
