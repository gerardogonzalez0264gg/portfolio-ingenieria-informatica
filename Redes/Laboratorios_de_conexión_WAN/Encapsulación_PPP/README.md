# Configuración de PPP en Packet Tracer

Esta actividad consiste en configurar y validar un enlace punto a punto usando el **protocolo PPP**, permitiendo la comunicación directa, cifrada o autenticada entre dos dispositivos.

# Glosario

PPP (Point To Point Protocol):  Permite establecer una conexión directa y segura entre dos nodos (puntos) para transmitir datos y autenticar usuarios.

three way handshake (SYN, SYN-ACK, ACK):  Lo que usan dos equipos para establecer una conexión TCP segura.
