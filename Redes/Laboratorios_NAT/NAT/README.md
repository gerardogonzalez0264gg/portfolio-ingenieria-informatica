# Explicación de NAT y PAT con configuración en Packet Tracer

NAT (traducción de dirección de red): Se utiliza para traducir la dirección IP privada a la dirección IP pública y viceversa.

ISP: Es la **compañía que te da acceso a Internet**.

ICMP: Protocolo de conectividad a través del ping

 |
 V

ICMP: es el protocolo de red que envía el mensaje de ida (_Echo Request_) y recibe el de vuelta (_Echo Reply_) para verificar si hay conectividad.

Se configurar **NAT Overload** en un router para que toda una red privada salga a Internet compartiendo una sola IP pública mediante tres pasos: definir los puertos (interno/externo), autorizar la red y activar la traducción.
