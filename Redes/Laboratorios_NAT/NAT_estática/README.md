# Configuración de NAT estática en Packet Tracer

Se configurar **NAT Estático**, enseña a etiquetar las interfaces del router (`inside`/`outside`) y mapear una IP privada a una pública para exponer un servidor local a Internet.

# Glosario:

mapeo de ip: traduce una IP pública a privada (entrante) o una privada a pública (saliente) o viceversa.

LAN: red local

WAN: red global
