# Inventario WEB

Aplicación web desarrollada para gestionar y organizar un inventario de productos de manera sencilla.

## 🎯 Objetivo

El objetivo de este proyecto es desarrollar una aplicación web que permita llevar un mejor control de los productos de un inventario, facilitando su visualización y administración.

Además, el proyecto busca aplicar conocimientos de **programación en Python, desarrollo web y diseño de interfaces**, utilizando Flask para crear la aplicación.

## 🛠️ Tecnologías utilizadas

* **Python**
* **Flask**
* **HTML**
* **CSS**

## 📁 Estructura del proyecto

* `app.py`: Archivo principal de la aplicación y contiene la lógica del sistema.
* `templates/`: Contiene las páginas HTML de la aplicación.
* `static/css/`: Contiene los archivos CSS utilizados para el diseño.
* `README.md`: Documentación del proyecto.

## ⚙️ Funcionalidades

* Visualización de productos.
* Gestión básica del inventario.
* Interfaz web sencilla.
* Organización de la información mediante una aplicación web.

## 🚀 Ejecución

Para ejecutar el proyecto se necesita tener **Python** instalado.

Instalar Flask:

```bash
pip install flask
```

Luego ejecutar:

```bash
python app.py
```

Finalmente, abrir en el navegador la dirección indicada por Flask.
