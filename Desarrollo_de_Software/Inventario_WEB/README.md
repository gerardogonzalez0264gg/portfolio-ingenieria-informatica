# Inventario WEB

Aplicación web desarrollada para facilitar la gestión y administración de un inventario de productos.

## 🎯 Objetivo

El objetivo principal de este proyecto es desarrollar una aplicación web sencilla que permita gestionar un inventario de manera más organizada, facilitando la visualización y administración de los productos.

El proyecto busca aplicar conocimientos de desarrollo de software, programación web y diseño de interfaces, utilizando Python y Flask como base para la aplicación.

## 🛠️ Tecnologías utilizadas

* **Python**
* **Flask**
* **HTML**
* **CSS**

## 📁 Estructura del proyecto

* `app.py`: Archivo principal de la aplicación.
* `templates/`: Contiene las páginas HTML.
* `static/css/`: Contiene los estilos utilizados en la aplicación.
* `README.md`: Documentación del proyecto.

## 🚀 Ejecución

Para ejecutar el proyecto:

1. Tener Python instalado.
2. Instalar Flask.
3. Ejecutar el archivo principal:

```bash
python app.py
```

4. Abrir en el navegador la dirección indicada por Flask.

## 📌 Funcionalidades

* Visualización del inventario.
* Gestión de productos.
* Interfaz web sencilla y fácil de utilizar.
* Organización de los archivos mediante una estructura básica de Flask.
