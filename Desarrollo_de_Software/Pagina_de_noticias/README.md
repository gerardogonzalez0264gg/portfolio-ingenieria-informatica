# Página de Noticias

Aplicación web desarrollada para la publicación y presentación de noticias de manera clara, ordenada y accesible.

## 🎯 Objetivo

El objetivo de este proyecto fue desarrollar una página web de noticias pensada para las necesidades de una **estudiante de Periodismo de la Universidad Bernardo O'Higgins**.

La plataforma busca facilitar la presentación de contenido periodístico mediante una interfaz sencilla y organizada, permitiendo mostrar las noticias de una forma atractiva para los lectores.

Este proyecto también permitió aplicar conocimientos de **desarrollo web, programación con Python, diseño de interfaces y manejo de aplicaciones web**.

## 🛠️ Tecnologías utilizadas

* **Python**
* **Flask**
* **HTML**
* **CSS**

## 📁 Estructura del proyecto

```text
Pagina_de_noticias/
│
├── app.py
├── templates/
├── static/
├── requirements.txt
├── Procfile
└── README.md
```

* `app.py`: Contiene la lógica principal de la aplicación.
* `templates/`: Contiene las páginas HTML del sitio.
* `static/`: Contiene los archivos utilizados para el diseño y estilos.
* `requirements.txt`: Contiene las dependencias necesarias para ejecutar el proyecto.
* `Procfile`: Archivo utilizado para la configuración del despliegue de la aplicación.
* `README.md`: Documentación del proyecto.

## ⚙️ Funcionalidades

* Presentación de noticias.
* Organización del contenido periodístico.
* Interfaz web sencilla y ordenada.
* Diseño orientado a la lectura de noticias.
* Estructura preparada para una aplicación web desarrollada con Flask.

## 🚀 Instalación y ejecución

Clonar el repositorio:

```bash
git clone https://github.com/gerardogonzalez0264gg/portfolio-ingenieria-informatica.git
```

Ingresar a la carpeta del proyecto:

```bash
cd portfolio-ingenieria-informatica/Desarrollo_de_Software/Pagina_de_noticias
```

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

Ejecutar la aplicación:

```bash
python app.py
```

Luego abrir en el navegador la dirección indicada por Flask.
