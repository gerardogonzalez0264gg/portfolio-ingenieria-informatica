
# Calculadora Web

## Descripción

Aplicación web desarrollada con HTML, CSS y JavaScript que permite realizar operaciones matemáticas básicas mediante una interfaz gráfica interactiva. Los usuarios pueden ingresar números, seleccionar operadores y visualizar los resultados directamente en pantalla.

## Objetivo

Desarrollar una calculadora web funcional para aplicar conocimientos de programación JavaScript, manipulación de elementos HTML y diseño de interfaces mediante CSS.

## Características principales

- Suma.
- Resta.
- Multiplicación.
- División.
- Ingreso de números mediante botones.
- Selección de operadores matemáticos.
- Visualización de operaciones y resultados.
- Limpieza de la pantalla.
- Interfaz gráfica interactiva.

## Tecnologías utilizadas

- HTML5: estructura de la aplicación.
- CSS3: diseño y estilos de la interfaz.
- JavaScript: lógica y ejecución de las operaciones matemáticas.

## Funcionamiento

La aplicación permite ingresar números y operadores mediante una interfaz de botones.

JavaScript procesa las operaciones matemáticas y muestra los resultados directamente en la pantalla.

## Ejecución

1. Descargar o clonar el repositorio.
2. Ubicar los archivos del proyecto.
3. Abrir el archivo `index.html` en un navegador web.
