# Calculadora 2.0

Proyecto desarrollado con **HTML, CSS y JavaScript** que permite realizar operaciones matemáticas básicas a través de una interfaz web. La calculadora permite ingresar números y realizar operaciones de suma, resta, multiplicación y división.

El funcionamiento se basa en una interfaz creada con **HTML**, mientras que **JavaScript** se encarga de agregar los números y operadores a la pantalla, limpiar la operación y calcular el resultado. Por otro lado, **CSS** se utiliza para el diseño de la página.
