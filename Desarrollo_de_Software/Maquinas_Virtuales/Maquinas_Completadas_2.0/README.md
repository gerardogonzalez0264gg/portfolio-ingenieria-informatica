
# Máquinas de Ciberseguridad

## Descripción

Aplicación web desarrollada para registrar, organizar y documentar máquinas virtuales resueltas de TryHackMe, durante el aprendizaje de ciberseguridad. Permite consultar un catálogo de máquinas, realizar búsquedas y acceder a documentación técnica sobre los procedimientos utilizados para resolverlas.

## Objetivo

Registrar y documentar el aprendizaje obtenido al resolver máquinas virtuales de ciberseguridad, facilitando la consulta de herramientas utilizadas, vulnerabilidades encontradas y procedimientos de resolución.

## Características principales

### Catálogo y búsqueda

- Catálogo de máquinas de ciberseguridad.
- Búsqueda por nombre completo o parcial.
- Búsqueda sin distinción entre mayúsculas y minúsculas.
- Búsqueda mediante la tecla Enter.
- Opción para visualizar todas las máquinas.

### Documentación técnica

- Walkthroughs para documentar la resolución de cada máquina.
- Registro de procesos de enumeración.
- Documentación de vulnerabilidades encontradas.
- Explicación de técnicas de explotación.
- Documentación de escalada de privilegios.
- Registro de herramientas y comandos utilizados.

### Interfaz y organización

- Visualización de walkthroughs mediante ventanas modales.
- Soporte para contenido Markdown.
- Visualización de código, títulos, enlaces e imágenes.
- Tarjetas interactivas.
- Código JavaScript organizado mediante funciones modulares.

## Tecnologías utilizadas

- HTML5.
- CSS3.
- JavaScript.
- Marked.js para interpretar contenido Markdown.

## Funcionamiento

La aplicación presenta las máquinas registradas mediante tarjetas interactivas.

El usuario puede buscar máquinas por su nombre y seleccionar una para consultar su información.

Los walkthroughs se visualizan dentro de una ventana modal, permitiendo consultar los procedimientos documentados sin abandonar la página.
