# Máquinas de Ciberseguridad

Aplicación web diseñada para registrar, organizar y documentar máquinas virtuales resueltas durante el aprendizaje de ciberseguridad.

Permite consultar las máquinas disponibles, buscar registros y acceder a documentación técnica sobre los procedimientos utilizados para resolverlas.

## Características principales

- Catálogo de máquinas de ciberseguridad.
- Búsqueda por nombre completo o parcial.
- Búsqueda sin distinción entre mayúsculas y minúsculas.
- Búsqueda mediante la tecla Enter.
- Opción para visualizar todas las máquinas.
- Documentación de procedimientos mediante walkthroughs.
- Visualización de walkthroughs en ventanas modales.
- Soporte para contenido Markdown.
- Visualización de código, imágenes, enlaces y títulos.
- Organización modular del código JavaScript.

## Información documentada

Cada walkthrough puede incluir:

- Enumeración de servicios.
- Identificación de vulnerabilidades.
- Técnicas de explotación.
- Escalada de privilegios.
- Herramientas y comandos utilizados.
- Procedimiento de resolución.

## Tecnologías utilizadas

- HTML5.
- CSS3.
- JavaScript.
- Marked.js (Markdown).

## Funcionamiento

La aplicación carga los registros de máquinas y los presenta mediante tarjetas interactivas.

El usuario puede buscar máquinas por nombre y abrir sus respectivos walkthroughs para consultar la documentación técnica sin abandonar la página.

## Objetivo

Mantener un registro organizado del aprendizaje práctico en ciberseguridad, documentando técnicas, herramientas y procedimientos utilizados en laboratorios de seguridad informática.
