# 🖥️ Máquinas Virtuales

Proyecto dedicado al **registro, organización y documentación de máquinas virtuales de ciberseguridad** resueltas durante el proceso de aprendizaje práctico.

El proyecto comenzó con una primera versión enfocada en registrar las máquinas completadas y posteriormente evolucionó a una segunda versión con nuevas funcionalidades para mejorar la búsqueda, organización y documentación de las resoluciones.

## 🎯 Objetivo

El objetivo es mantener un registro de las máquinas virtuales resueltas, incluyendo información como:

* Nombre de la máquina.
* Sistema operativo.
* Dificultad.
* Herramientas utilizadas.
* Proceso de resolución.
* Vulnerabilidades encontradas.
* Técnicas utilizadas durante la explotación y escalada de privilegios.

De esta forma, el proyecto funciona como un **registro personal de aprendizaje y práctica en ciberseguridad**.

## 📂 Versiones

### 📌 Máquinas Completadas — Versión 1.0

Primera versión del proyecto.

Su objetivo principal es mostrar un catálogo de las máquinas virtuales completadas, junto con información básica sobre cada una.

Incluye:

* Información de las máquinas.
* Sistema operativo.
* Dificultad.
* Herramientas utilizadas.
* Búsqueda de máquinas.
* Tarjetas para visualizar la información.

### 🚀 Máquinas 2.0 — Versión 2.0

Versión mejorada del proyecto, incorporando nuevas funcionalidades y una estructura de código más organizada.

Incluye:

* Búsqueda parcial y sin distinguir mayúsculas/minúsculas.
* Opción para mostrar nuevamente todas las máquinas.
* Búsqueda mediante la tecla `Enter`.
* Walkthroughs para documentar las resoluciones.
* Ventana modal para visualizar los walkthroughs sin salir de la página.
* Soporte para Markdown.
* Código JavaScript más modular.
* Mejoras visuales y de interacción.
* Nuevas máquinas.

## 📊 Evolución del proyecto

```text
Máquinas Completadas 1.0
        │
        │ Mejoras en funcionalidad,
```

La versión 2.0 mantiene la base de la primera versión, pero amplía sus funcionalidades para convertir el proyecto en una herramienta más completa para **documentar y consultar el aprendizaje obtenido durante la resolución de máquinas de ciberseguridad**.

Este proyecto forma parte de mi **portafolio de aprendizaje en Ingeniería Informática**, y busca demostrar el progreso en el desarrollo web y, especialmente, la aplicación práctica de conocimientos relacionados con **ciberseguridad, enumeración, explotación y escalada de privilegios**.
