# Calculadora

Proyecto desarrollado con **Python y Flask** que permite realizar operaciones matemáticas básicas mediante una interfaz web. La aplicación recibe dos números ingresados por el usuario y permite seleccionar entre suma, resta, multiplicación, división y porcentaje.

El funcionamiento se basa en un formulario HTML que envía los datos a Flask mediante una petición **POST**. El archivo `app.py` procesa la operación seleccionada y devuelve el resultado a la página. La interfaz está desarrollada con **HTML** y **CSS**.
