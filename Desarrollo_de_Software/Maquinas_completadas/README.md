# Máquinas completadas - TryHackMe

Este proyecto tiene como finalidad mostrar las diferentes máquinas y salas que he completado en **TryHackMe** como parte de mi aprendizaje y práctica en ciberseguridad.

La página web permite visualizar las máquinas realizadas junto con información como el **sistema operativo, dificultad y principales herramientas utilizadas** durante su resolución.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript
* JSON

## Funcionamiento

La información de las máquinas se encuentra almacenada en el archivo `maquinas.json`. JavaScript se encarga de leer estos datos y mostrarlos en la página web.

El objetivo de este proyecto es mantener un registro visual de las máquinas que he realizado y de las herramientas utilizadas, permitiendo ir agregando nuevas máquinas a medida que continúo aprendiendo y practicando en TryHackMe.
