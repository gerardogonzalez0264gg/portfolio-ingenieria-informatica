# Portafolio Web

Este proyecto corresponde a mi **portafolio web personal**, desarrollado con el objetivo de presentar de manera organizada mi información, proyectos y experiencia como estudiante de Ingeniería Informática.

El portafolio permite conocer mi perfil y visualizar parte de los trabajos y proyectos que he realizado durante mi formación académica, incluyendo actividades relacionadas con el **desarrollo de software y ciberseguridad**.

## Tecnologías utilizadas

* HTML
* CSS

## Contenido

El proyecto tiene con una página principal desarrollada en HTML y decorada con CSS. Además, incluye mi **currículum en formato PDF** para complementar la información presentada en el portafolio.

## Objetivo

El objetivo principal de este proyecto es contar con un espacio web donde pueda **presentar mis conocimientos, proyectos y trabajos realizados durante mi formación en Ingeniería Informática**, manteniendo un registro de mi progreso y aprendizaje.
