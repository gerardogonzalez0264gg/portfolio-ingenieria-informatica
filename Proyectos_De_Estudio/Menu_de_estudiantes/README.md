# Menú de estudiantes

## 📌 Descripción

Proyecto desarrollado en **Python** que permite administrar información de estudiantes mediante un menú de opciones.

El programa permite interactuar con diferentes funciones relacionadas con el registro y manejo de estudiantes desde la terminal.

## 🛠️ Tecnologías

- Python

## 🎯 Objetivo

Practicar conceptos básicos de programación en Python, como **funciones, variables, condicionales, ciclos y manejo de datos**, mediante la creación de un menú interactivo.
