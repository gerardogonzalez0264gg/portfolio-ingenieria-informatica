# 🔐 SecureBank API

> 🚧 **Proyecto en desarrollo**

Proyecto académico de **DevSecOps** que se encuentra actualmente en proceso de desarrollo. SecureBank API es una API bancaria simulada utilizada para estudiar arquitectura, seguridad y automatización mediante CI/CD.

## 🎯 Objetivo

El objetivo del proyecto es aplicar prácticas de **DevSecOps** durante el ciclo de desarrollo de software, integrando desarrollo, seguridad, pruebas y automatización.

También busca practicar el trabajo con ramas, Pull Requests, revisión de código e integración continua.

## 🏦 Descripción

El proyecto está organizado en diferentes componentes:

* `src/` → código fuente.
* `tests/` → pruebas.
* `docs/` → documentación y Threat Modeling.
* `.github/` → automatización y configuración del repositorio.
* `Dockerfile` → configuración para crear el entorno de la aplicación.
* `requirements.txt` → dependencias del proyecto.

## 🔄 Integración continua

El proyecto utiliza **GitHub Actions** para automatizar procesos relacionados con el desarrollo y validación de los cambios.

El flujo de trabajo está basado en **Pull Requests**, permitiendo revisar los cambios antes de integrarlos a las ramas principales.

## 🌿 Estrategia de ramas

Se utiliza una estrategia basada en diferentes tipos de ramas:

* `main` → código estable y liberado.
* `develop` → rama de integración.
* `feature/*` → desarrollo de nuevas funcionalidades.
* `hotfix/*` → correcciones urgentes.

Los cambios se integran mediante Pull Requests para mantener un proceso controlado de desarrollo.

## 🛡️ Seguridad

El proyecto incorpora prácticas relacionadas con:

* DevSecOps.
* Threat Modeling.
* Revisión de código.
* Protección de ramas.
* Gestión de secretos.
* Integración continua.

## 🧪 Pruebas

El proyecto cuenta con una carpeta `tests/` destinada a las pruebas del sistema.

Las pruebas forman parte del proceso de validación de los cambios realizados durante el desarrollo.

## 🐳 Docker

Se incluye un `Dockerfile` para facilitar la creación de un entorno reproducible para la aplicación.
