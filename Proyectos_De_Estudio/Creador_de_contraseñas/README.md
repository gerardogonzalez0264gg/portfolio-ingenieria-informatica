# Creador de contraseñas

## 📌 Descripción

Proyecto desarrollado en **Python** que permite generar contraseñas aleatorias de forma rápida, utilizando diferentes tipos de caracteres.

El programa permite crear contraseñas combinando **letras, números y caracteres especiales**, ayudando a generar contraseñas más difíciles de adivinar.

## 🛠️ Tecnologías

- Python
- Librerías `random` y `string`

## 🎯 Objetivo

Practicar conceptos de programación en Python, como el uso de **librerías, variables, ciclos y generación de datos aleatorios**, aplicándolos a la creación de contraseñas.
