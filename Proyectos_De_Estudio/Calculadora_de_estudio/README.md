# Alarma de estudio

Creé un programa con **Python** que permite ejecutar un sonido una vez haya transcurrido un cierto período de tiempo. El programa utiliza las librerías `time` y `winsound` para controlar el tiempo y reproducir una alarma al finalizar cada período.

El programa cuenta con una función llamada `reloj()`, que realiza una cuenta regresiva mostrando en la terminal los segundos restantes. Una vez finalizado el tiempo, reproduce el archivo `alarma.wav`.

Actualmente, el programa está configurado para realizar períodos de **30 minutos de estudio**, seguidos de **5 minutos de descanso**, repitiendo este ciclo de manera continua.
