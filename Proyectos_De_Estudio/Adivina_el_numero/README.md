# Adivina el número

## 📌 Descripción

Proyecto desarrollado en **Python** que consiste en un juego donde el usuario debe adivinar un número generado aleatoriamente por el programa.

El programa entrega pistas indicando si el número ingresado es **mayor o menor** que el número correcto y cuenta la cantidad de intentos realizados.

## 🛠️ Tecnologías

- Python
- Librería `random`

## 🎯 Objetivo

Practicar conceptos básicos de programación en Python, como **condicionales, ciclos, variables, entrada de datos y números aleatorios**.
