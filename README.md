* HTML

### Tecnologías y herramientas

* Node.js
* npm
* Git
* GitHub
* GitHub Actions
* CI/CD
* DevSecOps
* Automated Testing

### Objetivo

Comprender cómo integrar automatización, pruebas y buenas prácticas de seguridad dentro del ciclo de desarrollo de software.

📁 **Repositorio:** `securebank-api`
